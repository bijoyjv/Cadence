Cadence

A private desktop trading workspace.

What it is

Cadence is a personal desktop application for chart analysis and trade planning. It is built and used privately and is not offered as a public service, subscription or paid product.

Components

  • Interactive charting interface (planned: TradingView Advanced Charts)
  • Custom indicator engine written in Python
  • Own market data feed built on the Exness API
  • Watchlist of Exness instruments

Availability

The application runs locally on the developer's computer and is not available to the public. This page describes the project only.

Cadence is an independent project. It is not affiliated with or endorsed by TradingView or Exness. It does not provide financial advice.
