# Cadence

A private desktop trading workspace (in development).

## Overview
Cadence is a personal desktop application for chart analysis and trade planning.
It is developed and used privately. It is not a public service, subscription or paid product.

## Components
- Charting interface, planned on TradingView Advanced Charts
- Custom indicator engine written in Python
- Own market data feed built on the Exness API
- Watchlist of Exness instruments

## Status
In development. Runs locally, not publicly available.
